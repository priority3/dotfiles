# 申论阅卷规则（评分依据）

> 本文件有**两个来源**，冲突时以讲义为准：
> 1. **讲义口径**（《申论基础系统课》第 3 讲「阅卷和评分标准」，52:36）——讲师的实战经验，最贴近四川/国考实况
> 2. **行业口径**（中公、华图、成公等公开材料）——用于补齐讲义没细说的扣分项
>
> 两者都不是官方文件。评卷时必须向用户声明"这是模拟判卷"。

---

## 一、讲义口径（优先）

### 1. 阅卷机制：老师只给"安全分"

- 阅卷**按份计酬**，批多少份拿多少钱 → 没人愿意给你冒险的分数
- 10 分题他愿给 9 分，但另一个老师打得低，卷子来回几次既费时间又触发三评，还会被系统标记"这个老师阅卷有问题"
- 结果：**成绩大多落在 6 字头，上下浮动 5 分**——不是运气差，是机制
- 应对叫**利他**：让阅卷官一眼看出"这份比别的卷该多给两分"——分层清晰、关键词前置、字迹工整。不是做标记（那是违纪）

### 2. 双评机制

双评误差小取平均；误差大拉第三位老师；**第三评的分数与谁接近，最终就偏向谁**。
所以答案要"在两个老师眼里都好"——过于个性的表达、含糊的层次，都会让两个人给出不同分。

### 3. 小题（客观题）的采分点怎么拆

**先按问法拆分，再按要点分**——不是平均切成 N 等份。

以讲义原例说明：

> 「谈谈这三条黄河分别指的是什么，并说明它们是如何发挥作用的」15 分

```
问法拆解：
  第一问「三条黄河分别是什么」→ 3 分（第一条 1 + 第二条 1 + 第三条 1）
  第二问「如何发挥作用」    → 12 分（两个大要点，各 6 分）
                              6 分内部再拆成 2+1+1+1+1
```

推论：
- **题干的问法结构 = 分值结构**。凡"分别""并""以及"这类词，都是拆分信号
- 只有一问的概括题，才按要点数均分（如 15 分 = 5 点 × 3 分）
- 找齐材料里的**要素点**并把它们"充分融入答案"，就是高分

### 4. 呈现要求（直接影响得分）

- 层次必须让考官"一眼看到"：第一是什么、第二是什么，写清楚
- **不要让阅卷官在红格子上十行里找要点**——看不清就不给分
- 关键词前置、分条列点、每条一句小标题

### 5. 大作文：先定档，后给分

档位是先定区间、再在区间内给分（类似面试的 70/80/90 档）。

| 档位 | 判定特征 | 说明 |
|---|---|---|
| 一类 28—35 | 中心明确、立意深刻，材料与个人思考结合得当 | 要"来源于材料并高于材料" |
| 二类 21—27 | 立意正确、结构完整，论证较充分但深度略欠 | **多数认真备考者的目标区** |
| 三类 | 论证乏力、主题模糊（"A 也对、B 也对"） | 分水岭在立意是否明确 |
| 四类 | 从材料出发，缺少自己的感受 | 纯贴材料，没有判断 |
| 五类 | 严重背离题意、大量抄袭材料 | 反党反国家反人民直接 0 分 |

**跨档关键**：全篇约 1/3 来自材料、其余来自平时积累；抄材料抄到没有"我"，就是四类以下。
**三类的病根**：不能"你觉得"，要"命题人觉得"。

### 6. 规范用词（唯一稳定加分的硬功夫）

要写**现象背后的本质**，只写现象不得分：

| 日常说法（抄材料） | 规范表述（得分） |
|---|---|
| 大声喧哗、不顾及别人感受 | 公共意识差 |
| 随意丢弃果皮纸屑 | 环保意识淡薄 |
| 干多干少都一样 | 奖惩机制缺失 |
| 不知道向谁投诉 | 投诉渠道不畅 |
| 货物积压卖不出去 | 销售渠道不畅 |
| 中看不中用 | 形式主义 |
| 路边随意摆摊 | 占道经营 |
| 感觉自己啥也不会 | 本领恐慌 |

评分时**单列一项检查**：整段抄材料现象、没有提炼词的，即使要点方向对也只能给"半中"。

## 二、行业口径（补讲义未覆盖的扣分项）

| 项 | 规则 |
|---|---|
| 客观题给分 | 采分点每点 2–4 分；答中采分词或同义替换得满分 |
| 多写 | 不额外扣分，但无关内容会挤占字数 |
| 错别字 | 每 2–3 个扣 1 分，重复不计，最多扣 2 分 |
| 超字数 | 每超 30–50 字扣 1 分 |
| 大作文无标题 | 扣 2 分 |
| 大作文字数不足 | 每少 50 字扣 1 分，最多扣 3 分 |
| 卷面 | 大面积涂改、字迹难辨扣 1–3 分 |
| 应用文 | 内容约 70%、格式约 30%（格式错比不写更亏） |

> 注：行业口径里大作文按 40 分制分五档（一类 31–40、二类 21–30、三类 11–20、四类 ≤10）；
> 讲义口径的 28—35／21—27 是讲师的实战区间。两者并存，评分时按题目满分换算，并说明用的是哪一套。

## 三、评分动作（六步）

1. **判题型**：看题干动词——概括（只抄）／分析（拆层）／提出（只写对策）／写一份 X（看文种）／写文章（定档）
2. **拆分值**：先按问法分块（"分别""并"），只有一问才按要点均分
3. **建采分点表**：每点写清「采分词 + 材料依据（第几则哪句）+ 分值」
4. **比对**：命中（含同义替换）＝满分；半中（方向对、缺采分词或只抄现象）＝50%；漏＝0
5. **扣分项**：错别字、超字数、卷面
6. **利他检查**：分条了吗？关键词前置了吗？考官能一眼看到层次吗？——不达标要在评语里点出来，因为这是真实失分点

## 四、禁忌

- 不设"条理分""印象分"这类自造维度
- 不编造材料里没有的数字和做法
- 用户明显跑题时，先指出审题错误，不要装模作样按点给分
