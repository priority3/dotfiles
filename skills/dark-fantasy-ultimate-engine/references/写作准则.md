# 写作准则

## 联网铁律

1. 只要涉及现实历史、地理、金融、法律、武器、帮派、职业流程、医疗、科技参数，就默认联网核验。
2. 首轮结果不够准时，必须改关键词继续查，至少做一次术语扩展或反向检索。
3. 关键事实至少交叉核对 2 个来源；高风险内容优先看一手资料或权威媒体。
4. 来源冲突时要显式写出冲突点，不得装作没有分歧。
5. 联网结果只能用于综合判断，不能拼贴式搬运。

## 角色构建六步

1. 角色目标：他现在最想要什么，短期和长期分别是什么。
2. 核心缺口：他缺什么，所以才会做出当前选择。
3. 行为底线：他绝不会做什么，一旦突破就必须给出代价。
4. 情绪扳机：什么会让他失控、迟疑、暴走或退让。
5. 对外关系：他对主角、盟友、敌人、家人分别怎样说话和行动。
6. 成长代价：每一次变强都要伴随失去、受伤、误判或债务。

## 雷点库

- 为推进剧情强行降智。
- 反派突然泄露不该知道的关键信息。
- 主角连续白嫖收益，没有代价和风险。
- 前文铺垫的威胁在后文自动失效。
- 关键冲突靠巧合化解。
- 同一类爽点连续重复，读感发麻。
- 台词全是态度，没有信息量和角色差异。

## 节奏控制

- 每章至少推进一项：局势、关系、信息、代价、收益。
- 高压章节优先短句和动作链，低压章节再补观察、回忆、判断。
- 连续两章爆发后，至少补一次清算或后果回收。
- 连续三章信息输入但没有兑现时，要安排一个明确回报点。
- 章节结尾尽量留钩子，但钩子必须和当前冲突直接相关。
- 超长篇默认慢节奏推进，但慢不等于停；每章都要有可被读者感知的净变化。
- 细腻重点放在局势张力、人物试探、情绪走向、代价兑现，不要把篇幅浪费在极致入微的环境描写上。

## 港综骨架

- 主骨架必须来自港综叙事逻辑：江湖秩序、地盘利益、警匪博弈、社团层级、人情债与面子账。
- 现实世界细节只负责补强可信度，不负责抢走港综主线。
- 写港综人物时，要重视身份、辈分、场面、试探、留手与翻脸成本。
- 冲突升级必须符合港综语境，不要把人物写成只会直线开打的工具人。

## 连载一致性复盘

- 写第 `n` 章前，先核对第 `1` 至第 `n-1` 章已确定的信息，至少保证与本章直接相关的部分全部对齐。
- 逐条核对：时间线、地点切换、人物在场与缺席、伤势恢复进度、道具归属、关系变化、已开副线、未回收伏笔。
- 若发现旧章矛盾，先修正认知或修补承接，后写新章，不得带着已知冲突继续推进。
- 无法确认的细节要保守处理，宁可少写一步，也不要强造设定。

## 主线与支线管理

- 主线只保留当前最强驱动力，不要同层并排堆三个大目标。
- 支线必须服务主线，至少满足其一：补资源、补情报、补关系、补动机。
- 同时挂起的支线不宜过多；超过 5 条时，要合并或砍掉弱线。
- 旧伏笔超过若干章未触发时，要么回收，要么升级成新矛盾。
- 每条副线都要记录当前状态，不能在续写时凭印象处理。
- 群像角色要均衡分配存在感，但不能让支线人物抢走主角的决策权和主驱动。

## 金手指平衡

- 金手指负责打开上限，不负责抹平代价。
- 每次大收益都要回答三个问题：为什么现在能拿到、代价是什么、后患是什么。
- 同档资源的收益增长若明显异常，必须给出来源差异或环境加成。
- 越接近核心外挂，越需要限制条件、冷却、污染、反噬、窥视成本等制衡。

## 包装优化

- 优先写“动作 + 反应 + 代价 + 收益”，少写抽象判断。
- 能用细节证明狠，就不要靠台词宣布狠。
- 冲突场面避免连续使用同一套形容词和句式。
- 爽点出现后，立刻补一笔风险或更大麻烦，形成拉扯感。
- 不要强制制造愚蠢误会，不要靠所有人集体降智给主角送戏。
- 情绪要拉满，但情绪必须来源于人物处境和选择，不靠空转独白硬拔高度。

## 现实题材考据要求

- 黑帮、金融、军火、执法、跨境、洗钱、毒品等内容只做背景化和叙事化处理。
- 不提供现实可执行的违法步骤、规避方法、采购链路、操作细节。
- 若用户要求相关内容，改写为历史背景、制度风险、法律后果，或纯虚构设定建议。
